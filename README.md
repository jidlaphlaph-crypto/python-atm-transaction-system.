# Python ATM Transaction System

## Project Overview
A terminal-based Python application that simulates core banking and ATM operations. The system establishes a local relational database to register new user details, safely process cash deposits, authenticate user login credentials, and dynamically update account balances.

## Tech Stack
* **Language:** Python 3
* **Database Engine:** SQLite3 (Built-in relational database)
* **Libraries:** Pandas (For data handling and structured logs)

## How to Run
Follow these simple commands in your terminal or PowerShell window to run the script:

1. Clone or download this project folder to your local machine.
2. Open your terminal or command prompt inside the project folder.
3. Execute the script using:
   ```bash
   python name_of_your_file.py
   ```
